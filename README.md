# Digital Onboarding & Fraud Risk Analytics

Projeto de análise de risco e prevenção a fraudes no onboarding digital.

## Tecnologias
- Python
- Pandas
- NumPy
- Machine Learning
- Scikit-learn

## Objetivo
Identificar sinais suspeitos em propostas de abertura de contas digitais utilizando dados sintéticos.

Projeto educacional. Não utiliza dados reais de clientes.
